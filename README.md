## Overview

Cancer neuroscience highlights the critical role of neural signaling in tumor biology, yet a comprehensive pan-cancer understanding of neuroregulatory dysregulation remains lacking. Here, we systematically characterized 130 neurotransmitter receptor (NTR) genes across 9,125 tumors from 33 cancer types, and performed validation using multiple independent cohorts. This repository aims to share the analytical workflows, processed data, and supporting resources to facilitate deeper understanding of this study, enable reproducibility, and support reuse of results of interest by readers and reviewers. Detailed package version specifications, complete parameter settings for the major analytical procedures, and guidance for the core analysis steps are provided in the README.md file. Additional scripts implementing specific functions can be accessed by referencing the corresponding script files.

## Instructions for Core Analytical Procedures
### 1. Annotating Genomic Point Mutations and Short Indels (GATK Funcotator)


#### Requirements

- **Java:** 1.8  
- **GATK4:** 4.6.2.0  


#### Execution Command

```bash
./gatk Funcotator \
  --variant variants.vcf \
  --reference Homo_sapiens_assembly19.fasta \
  --ref-version hg19 \
  --data-sources-path funcotator_dataSources.v1.8.hg19.20230908s \
  --output variants.funcotated.maf \
  --output-file-format MAF \
  --ignore-filtered-variants false \
  --transcript-selection-mode CANONICAL
```

#### Parameter Description

- **--variant:** Path to the input VCF file containing variants to be annotated.
- **--reference:** Path to the reference genome sequence in FASTA format.
- **--ref-version:** Human reference genome build identifier (e.g., `hg19`, `hg38`).
- **--data-sources-path:** Path to the Funcotator data sources directory. Data sources can be downloaded from the Broad Institute public bucket (Google Cloud Storage browser).
- **--output:** Output file path for annotated variants.
- **--output-file-format:** Output format (`VCF`, `MAF`, or `SEG`).
- **--ignore-filtered-variants:** Whether to exclude variants that are marked as filtered in the input VCF. If set to `true`, filtered variants will be omitted from the output.
- **--transcript-selection-mode:** Transcript selection strategy for detailed annotation (`CANONICAL`, `ALL`, or `BEST_EFFECT`).

#### References

- **GATK Funcotator documentation:**
  https://gatk.broadinstitute.org/hc/en-us/articles/360035889931-Funcotator-Information-and-Tutorial

- **Broad Institute Funcotator data sources (Google Cloud Storage browser):**
  https://console.cloud.google.com/storage/browser/broad-public-datasets/funcotator

### 3. Identifying Conditional Selection between Alterations (Mutual Exclusivity and Co-occurrence)

#### Requirements

- **R:** version 4.0.2
- [SELECT](http://ciriellolab.org/select/select.html): version 1.6

#### Execution Command

```r
select(
  M = altData,
  sample.class = sample.class,
  alteration.class = alteration.class,
  folder = "select/results/",
  min.feature.support = 10,
  min.feature.freq = 0.005,
  n.permut = 1000,
  r.seed = 110,
  n.cores = 32,
  calculate_APC_threshold = FALSE
)
```

#### Parameter Description

- **M:** Binary alteration matrix of shape (samples x features) used for conditional selection analysis.
- **sample.class:** Vector of sample-level class labels.
- **alteration.class:** Vector of feature labels corresponding to the columns of **M**.
- **folder:** Output directory where SELECT writes results and intermediate files.
- **min.feature.support:** Minimum number of altered samples required to retain a feature.
- **min.feature.freq:** Minimum alteration frequency required to retain a feature.
- **n.permut:** Number of permutations used to estimate statistical significance.
- **r.seed:** Random seed for reproducibility.
- **n.cores:** Number of CPU cores used for parallel computation.
- **calculate_APC_threshold:** Logical flag; if set to `FALSE`, APC threshold estimation is skipped.

#### References

- **For detailed documentation, tutorials, and advanced parameter settings, please refer to the [select](http://ciriellolab.org/select/select.html) repository.**


### 4. Identification of Differentially Expressed Genes (limma)


#### Requirements

- **R:** version 4.0.2
- [limma](https://bioconductor.org/packages/release/bioc/html/limma.html): version 3.58.1


#### Execution Command

```r
# Fit a linear model for each gene
fit <- lmFit(object = eset, design = design)
# Apply empirical Bayes moderation
fit <- eBayes(fit = fit)
# Extract differential expression results
topTable(
  fit,
  coef = "typeTumor",
  adjust.method = "BH",
  n = Inf
)
```

#### Parameter Description

- **object:** Matrix-like expression object containing log-transformed values; rows correspond to genes and columns correspond to samples.
- **design:** Design matrix specifying the experimental model; rows correspond to samples and columns correspond to model coefficients to be estimated.
- **fit:** Fitted limma model object returned by `lmFit()`, subsequently updated by `eBayes()`.
- **coef:** Column name or index in the design matrix indicating the coefficient (contrast) tested for differential expression.
- **adjust.method:** Multiple-testing correction method applied to $p$-values (e.g., Benjamini–Hochberg, `"BH"`).
- **n:** Maximum number of genes returned (use `Inf` to return all genes).

#### References

- **For comprehensive documentation, tutorials, and advanced parameter settings, please refer to the [limma](https://bioconductor.org/packages/release/bioc/html/limma.html) package.**


### 5. Identification of Neuroregulatory Subtypes by Consensus Clustering

#### Requirements

- **R:** version 4.0.2
- [ConsensusClusterPlus](https://bioconductor.org/packages/release/bioc/html/ConsensusClusterPlus.html): Version 1.66.0

#### Execution Command

```r
- # ConsensusClusterPlus function for determing cluster number and class membership by stability evidence.
- ConsensusClusterPlus(
-   d = dt,
-   maxK = 9,
-   reps = 100,
-   pItem = 0.8,
-   pFeature = 1,
-   clusterAlg = "hc",
-   title = "hcPearsonWardAverCluster",
-   innerLinkage = "ward.D2",
 -  finalLinkage = "average",
-   distance = "pearson",
-   ml = NULL,
-   tmyPal = NULL,
-   seed = 1024,
-   plot = "png",
 -  writeTable = FALSE,
- weightsItem = NULL,
- weightsFeature = NULL,
- verbose = TRUE,
- corUse = "pairwise.complete.obs"
- )
```

#### Parameter Description

- **d:** Input data matrix to be clustered (typically features $\times$ samples or samples $\times$ features, depending on the workflow).  
- **maxK:** Maximum number of clusters to evaluate.  
- **reps:** Number of resampling iterations (subsamples) used to construct the consensus matrix.  
- **pItem:** Proportion of items (samples) to subsample in each iteration.  
- **pFeature:** Proportion of features to subsample in each iteration.  
- **clusterAlg:** Clustering algorithm applied to each subsample (e.g., `"hc"`, `"km"`).  
- **title:** Character string specifying the output directory prefix/name.  
- **innerLinkage:** Linkage method used for hierarchical clustering within each subsample.  
- **finalLinkage:** Linkage method used to cluster the final consensus matrix.  
- **distance:** Distance metric used for clustering (e.g., `"euclidean"`, `"pearson"`, `"spearman"`).  
- **ml:** Optional prior result object; if provided, computation is skipped and only figures/tables are generated.  
- **tmyPal:** Optional character vector defining the color palette for consensus matrix visualization.  
- **seed:** Random seed to ensure reproducibility.  
- **plot:** Output mode for plots: `NULL` (display on screen), `"pdf"`, `"png"`, or `"pngBMP"` (bitmap PNG; recommended for large datasets).  
- **writeTable:** Logical flag; if `TRUE`, writes output tables and logs to CSV files.  
- **weightsItem:** Optional sampling weights for items (samples).  
- **weightsFeature:** Optional sampling weights for features.  
- **verbose:** Logical flag; if `TRUE`, prints progress messages to the console.  
- **corUse:** Specifies how missing values are handled when using correlation-based distances.  

#### References

- **For detailed documentation, tutorials, and advanced parameter settings, please refer to the [ConsensusClusterPlus](https://bioconductor.org/packages/release/bioc/html/ConsensusClusterPlus.html) Bioconductor repository.**
